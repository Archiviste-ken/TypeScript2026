🧠 Type Inference (One of TypeScript's Best Features)

You usually don't need to write types.

Example:

let age = 20;

TypeScript automatically infers:

let age: number

Similarly:

let name = "Alex";

becomes

let name: string

and

let online = true;

becomes

let online: boolean

This is called type inference.

💡 Rule of thumb: Let TypeScript infer types when it's obvious. Add explicit types when they improve clarity or are required (like function parameters, object shapes, APIs, etc.).
